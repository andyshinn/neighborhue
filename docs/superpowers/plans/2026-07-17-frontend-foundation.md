# Frontend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `apps/web` from a bare package scaffold into a deployed TanStack Start app on `neighborhue.app` that server-renders one real route (`/n/:id`) against the live API — proving the whole foundation (SSR, loader→Query hydration, the type seam, the color model, tokens, fonts, deploy) works before Spec 2 builds the four screens.

**Architecture:** TanStack Start (Vite + React 19 + TanStack Router) deployed as a Cloudflare Worker with selective per-route SSR. A CSS-custom-property token layer over Radix Colors themes light/dark by cascade; the daily hue is one variable set on one element. Data flows through TanStack Query with SSR-time cache priming; the API is reached by public `fetch` to `api.neighborhue.app`. The readable-ink derivation is a pure function, unit-tested against the seeded palettes.

**Tech Stack:** TanStack Start 1.168, TanStack Router 1.170, TanStack Query 5.101, `@tanstack/react-router-ssr-query` 1.167, React 19.2, Vite 8.1, `@cloudflare/vite-plugin` 1.45, `@vitejs/plugin-react` 6, Radix Colors 3, Radix Primitives, `@fontsource-variable/geist(-mono)` 5, Vitest 4 + Testing Library 16 + happy-dom, Wrangler 4.

**Source of truth:** [`docs/superpowers/specs/2026-07-17-frontend-foundation-design.md`](../specs/2026-07-17-frontend-foundation-design.md) (this plan's spec) and [`docs/handoff/neighborhue/design_handoff_neighborhue/README.md`](../../handoff/neighborhue/design_handoff_neighborhue/README.md) (design values). Where they disagree on palette data, **the live API wins** (spec §11).

## Global Constraints

Copied verbatim from the spec; every task's requirements implicitly include these.

- **Scope is the walking skeleton only.** The four screens (Home, Create, Share, Manage) are Spec 2. `/n/:id` here is the *minimal honest* Share page — background hue + computed ink + hex + name as text. No layout, countdown, panel, glow, or logo. Do not attempt the Share page. (spec §3)
- **Never replicate the API's color *selection* (`pickColorIndex`) client-side.** The API returns `color`; only the readable-ink derivation is client-side. Replicating selection would require a *runtime* import from `@neighborhue/api`, which the monorepo spec §4 forbids. (spec §6.2, W10)
- **`apps/web` imports types only from `@neighborhue/api`.** A runtime-value import would pull untranspiled TypeScript into Vite's graph. (monorepo spec §4)
- **`?format=hex|rgb` on `GET /:id` is public API** the Home Assistant integration depends on ([`README.md:46`](../../../README.md)). The hc-consumption fix is client-side; never remove or split the formats. (spec §7.1)
- **The manage secret lives in the URL `#fragment`, never the path** — fragments are not transmitted to servers. (spec §4.4, W9)
- **`prefers-reduced-motion: reduce` disables all animation/transition.** No motion is added in this plan, but any CSS transition introduced must respect it. (handoff)
- **Always render hex + name** wherever a color is shown — meaning never depends on color alone. (spec §6.1)
- **Wrangler is a per-app devDependency**, not hoisted to the root (monorepo spec M15). `apps/web` needs `wrangler ^4.112.0` (the `@cloudflare/vite-plugin` peer floor).
- **Package manager is pnpm; formatter/linter is Biome** (single root config). Run `pnpm check` (Biome) and `pnpm -r typecheck` before every commit.
- **Commit `src/routeTree.gen.ts`** (generated by the Start Vite plugin). It is not hand-edited, but it is committed so `pnpm -r typecheck` stays hermetic in CI.

```tsx
import { QueryClient } from '@tanstack/react-query'
import { createRouter } from '@tanstack/react-router'
import { setupRouterSsrQueryIntegration } from '@tanstack/react-router-ssr-query'
import { routeTree } from './routeTree.gen'

// Loaders prime this cache at SSR time; components read it via useQuery, so
// server-rendered data hydrates into the same cache the client mutates
// (spec W7). `setupRouterSsrQueryIntegration` is the current form of the
// spec's `routerWithQueryClient`; the intent is unchanged.
export function getRouter() {
  const queryClient = new QueryClient()
  const router = createRouter({
    routeTree,
    context: { queryClient },
    scrollRestoration: true,
    defaultPreload: 'intent',
  })
  setupRouterSsrQueryIntegration({ router, queryClient })
  return router
}

declare module '@tanstack/react-router' {
  interface Register {
    router: ReturnType<typeof getRouter>
  }
}
```

```ts
export type Ink = '#181310' | '#ffffff'

export interface ColorTheme {
  ink: Ink
  inkMuted: string
  chipBg: string
  lockup: 'light' | 'dark-text'
}

function toRgb(hex: string): [number, number, number] {
  const h = hex.replace('#', '')
  return [
    parseInt(h.slice(0, 2), 16),
    parseInt(h.slice(2, 4), 16),
    parseInt(h.slice(4, 6), 16),
  ]
}

// sRGB → linearized relative luminance (WCAG). 0.2126R + 0.7152G + 0.0722B.
export function relativeLuminance(hex: string): number {
  const linear = toRgb(hex).map((c) => {
    const s = c / 255
    return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4
  })
  return 0.2126 * linear[0] + 0.7152 * linear[1] + 0.0722 * linear[2]
}

export function alpha(hex: string, a: number): string {
  const [r, g, b] = toRgb(hex)
  return `rgba(${r}, ${g}, ${b}, ${a})`
}

// Ink is whichever of near-black / white has higher contrast against the hue.
// Note: contrast is computed against pure black but rendered as #181310 (warm
// near-black); the discrepancy is negligible (spec §6.1).
export function colorTheme(hex: string): ColorTheme {
  const L = relativeLuminance(hex)
  const ink: Ink = (L + 0.05) / 0.05 >= 1.05 / (L + 0.05) ? '#181310' : '#ffffff'
  return {
    ink,
    inkMuted: alpha(ink, 0.68),
    chipBg: alpha(ink, 0.12),
    lockup: ink === '#ffffff' ? 'light' : 'dark-text',
  }
}
```

```ts
export interface ApiErrorBody {
  error: string
  message: string
}

export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
  ) {
    super(message)
    this.name = 'ApiError'
  }
}

export class NeighborhoodNotFound extends ApiError {
  constructor(message = 'Unknown neighborhood') {
    super(404, 'neighborhood_not_found', message)
    this.name = 'NeighborhoodNotFound'
  }
}

export function parseApiErrorBody(body: unknown): ApiErrorBody | null {
  if (
    body &&
    typeof body === 'object' &&
    typeof (body as { error?: unknown }).error === 'string' &&
    typeof (body as { message?: unknown }).message === 'string'
  ) {
    return body as ApiErrorBody
  }
  return null
}
```

```ts
import type { PublicNeighborhood } from '@neighborhue/api/types'
import { createClient } from './client'
import { ApiError, NeighborhoodNotFound, parseApiErrorBody } from './errors'

// Restores a real type over hc's `unknown` for GET /v1/neighborhoods/:id.
// Importing PublicNeighborhood (not restating it) keeps the compile-time
// seam: a field rename in apps/api fails this file's typecheck (spec §7.1).
export async function fetchNeighborhood(baseUrl: string, id: string): Promise<PublicNeighborhood> {
  const res = await createClient(baseUrl).v1.neighborhoods[':id'].$get({ param: { id } })
  if (res.ok) {
    return (await res.json()) as PublicNeighborhood
  }
  const body = parseApiErrorBody(await res.json().catch(() => null))
  if (res.status === 404) throw new NeighborhoodNotFound(body?.message)
  throw new ApiError(res.status, body?.error ?? 'error', body?.message ?? `Request failed: ${res.status}`)
}
```

```tsx
import { createFileRoute, notFound } from '@tanstack/react-router'
import { useSuspenseQuery } from '@tanstack/react-query'
import { ColorField } from '../components/ColorField'
import { NeighborhoodNotFound } from '../lib/errors'
import { neighborhoodQueryOptions } from '../lib/queries'

export const Route = createFileRoute('/n/$id')({
  // SSR (default): the hue paints with zero JS and OG tags unfurl.
  loader: async ({ context, params }) => {
    try {
      // Primes the Query cache so the component's useSuspenseQuery is a hit.
      await context.queryClient.ensureQueryData(neighborhoodQueryOptions(params.id))
    } catch (err) {
      // Unknown id → real 404 status, not a 200 rendering a 404-shaped page.
      if (err instanceof NeighborhoodNotFound) throw notFound()
      throw err
    }
  },
  head: ({ params }) => {
    // head cannot await; read the primed cache is not available here, so
    // derive OG from params-independent copy plus the id. The dynamic color
    // title is set from loader data via the component's document title in
    // Spec 2; for the skeleton, static-but-present OG tags satisfy §9.2.
    return {
      meta: [
        { title: 'Neighborhue — today’s color' },
        { property: 'og:title', content: 'Neighborhue' },
        { property: 'og:description', content: 'The whole neighborhood glows the same color today.' },
      ],
    }
  },
  component: ShareSkeleton,
})

function ShareSkeleton() {
  const { id } = Route.useParams()
  const { data } = useSuspenseQuery(neighborhoodQueryOptions(id))
  return <ColorField name={data.name} color={data.color} />
}
```
